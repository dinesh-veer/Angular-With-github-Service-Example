About GitHub Explorer

GitHub Explorer is a responsive Angular application that lets you search and explore repositories, developer profiles, and repository issues using the official GitHub REST API v3.

  • Framework: Angular 21 (CLI 21, TypeScript 5.9, RxJS 7.8)
  • API Service: Centralized HttpClient service with real-time rate-limit tracking
  • Search Engine: Reactive debounced search with query cancellation
  • Endpoints: Repositories, Users, Issues, Commits, Contributors, Languages, README

Note: GitHub allows 60 unauthenticated requests/hour per IP address and 10 search queries/minute. The app displays real-time remaining quotas.
